# Namida Assets

Images and other files used by [Namida](https://github.com/namidaco/namida), its readme, Flathub listing and [docs](https://docs.namida.app), kept here so they stay out of the app repo's history.

## Screenshots

Generated by `scripts/screenshots` in the namida repo (`compose.py --publish`), every folder is replaced whole on each run, don't edit them by hand.

| Folder | Used by |
| --- | --- |
| `screenshots/readme/` | the readme collections and settings pages |
| `screenshots/flathub/` | the Flathub metainfo (`linux/packaging/com.msob7y.namida.metainfo.xml.in`) |
| `screenshots/docs/<platform>/<theme>/` | docs pages, `android` and `windows`, `light`/`dark`/`black` |
| `screenshots/designs/` | composed images not placed anywhere yet (hero, light/dark split) |

`screenshots/manual/` holds hand-taken shots the generator can't make yet (the android youtube miniplayer), the
generator never touches it. 

`screenshots_2023/` is the old readme set, kept for the readme's "2023 Screenshots".
